# WyVault Lite

An open-source hardware wallet for **Nervos CKB** (and Bitcoin) built on an ESP32-S3 with a touchscreen. It is the low-cost sibling of [WyVault](https://github.com/toastmanAu/WyVault) (ESP32-P4). The repo also includes a plugin that lets the [Neuron](https://github.com/nervosnetwork/neuron) desktop wallet use the device as a signer over USB.

> [!WARNING]
> **Scaffold — do not use with real funds.** The application structure, UI states, encrypted storage layout and USB protocol are in place. The cryptography is **not**: BIP39, BIP32 and signing in `main/crypto.c` are stubs, the PIN key derivation in `main/storage.c` is a SHA-256 placeholder rather than PBKDF2, and the fingerprint driver is a stub. A seed generated by this firmware is not secure.

## Target hardware

- **Guition JC3248W535** (ESP32-S3-WROOM-1U-N16R8: 16 MB flash, 8 MB PSRAM)
- AXS15231B 320×480 QSPI display, CST820 I2C touch
- Optional **SFM-V1.7** optical fingerprint sensor (UART, 57600 baud) as a second factor

## Planned design

```
Boot → flash-encryption check → PIN → Home (accounts) | Sign | Settings
Sign: unsigned tx over USB CDC → review on screen → approve → signature back to host
```

- **Seed at rest.** AES-256-GCM, with the key derived by HKDF from `PIN ‖ device_secret` and a random salt. The ciphertext, IV and salt are stored in NVS (`main/storage.c`).
- **Flash encryption.** AES-XTS is checked at boot. The firmware warns in development builds and halts when built with `CONFIG_WYVAULT_REQUIRE_FLASH_ENC`. Secure Boot v2 is to be enabled once the firmware is stable.
- **Lockout.** 5 wrong PIN attempts.
- **Signing isolation.** Wi-Fi is off during signing.
- **Two logical wallets.** Cold `m/44'/309'/0'` signs with on-device approval. Hot `m/44'/309'/1'` is a connected-mode wallet managed on the device.
- **Crypto.** Planned integration of trezor-crypto (BIP39/BIP32/secp256k1) and BLAKE2b for CKB's `secp256k1_blake160_sighash_all` lock.

## Repository layout

| Path | Contents |
|---|---|
| `main/` | ESP-IDF firmware: state machine, UI, crypto API (stubbed), encrypted storage, fingerprint driver (stubbed) |
| `neuron-plugin/` | TypeScript plugin implementing Neuron's `Hardware` interface over USB CDC. See its [README](neuron-plugin/README.md) for the JSON protocol (`ping`, `get_pubkey`, `sign_tx`, `get_status`). |
| `partitions.csv` | 16 MB layout: NVS, 3 MB app, ~13 MB FAT `storage` partition (reserved, not yet used) |
| `sdkconfig.defaults` | mbedTLS GCM/HKDF/SHA-512, custom partition table |

## Build

Requires [ESP-IDF](https://docs.espressif.com/projects/esp-idf/) v5.x.

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

Neuron plugin:

```bash
cd neuron-plugin
npm install
npm run build
```
